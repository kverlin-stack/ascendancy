# Decisions

Design and tech choices the brief didn't settle. Newest at the bottom. Flag anything here you want changed.

| Date       | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Why                                                                                                                                                                                                                                                                      |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 2026-11-26 | **One turn = one month.** A quarter is 3 turns, a year is 12. The enemy's quarterly advance happens at the end of turns 3, 6, 9...                                                                                                                                                                                                                                                                                                                                                                                                           | "Advances every quarter" needs a turn length. Monthly turns give a few turns of play between advances, so the advance feels like a deadline.                                                                                                                             |
| 2026-11-26 | **End of turn order:** telegraphed enemy action, then the quarterly advance, then lose checks, then discard and draw.                                                                                                                                                                                                                                                                                                                                                                                                                        | Lets you see both hits coming and answer them in the same turn.                                                                                                                                                                                                          |
| 2026-11-26 | **The enemy action is shown for the current turn** and resolves when you press End Turn. It's picked at random, weighted, from the threat list.                                                                                                                                                                                                                                                                                                                                                                                              | Same model as Slay the Spire's enemy intent. Proper director logic comes in Phase 1.                                                                                                                                                                                     |
| 2026-11-26 | **Winning is instant:** the moment Progress reaches the goal, the run ends, even mid-turn.                                                                                                                                                                                                                                                                                                                                                                                                                                                   | Matches the brief's "two territories from the capital when Sunfire came online" story beat.                                                                                                                                                                              |
| 2026-11-26 | **The Front counts territories held** (10 at the start, 0 means the capital falls). `pushFront` can't go past the starting line.                                                                                                                                                                                                                                                                                                                                                                                                             | It's the simplest number to read on a phone.                                                                                                                                                                                                                             |
| 2026-11-26 | **`protectSecrecy` restores Secrecy** (capped at 10). It doesn't block incoming hits.                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Simple for Phase 0. "Counter them or take the hit" (blocking a telegraphed action) is a Phase 1 design question.                                                                                                                                                         |
| 2026-11-26 | **Added a 6th card primitive, `gainMorale`.** Negative amounts on `gainBudget`, `gainMorale` and `protectSecrecy` act as costs.                                                                                                                                                                                                                                                                                                                                                                                                              | Nothing could restore Morale without it. Negative amounts let cards carry costs without adding more primitives.                                                                                                                                                          |
| 2026-11-26 | **Enemy actions use their own primitives:** `advanceFront`, `loseSecrecy`, `loseBudget`, `loseMorale`.                                                                                                                                                                                                                                                                                                                                                                                                                                       | Easier to read in data than negative card effects, and keeps card and enemy effects separate.                                                                                                                                                                            |
| 2026-11-26 | **A card can't be played if its cost would take Budget, Morale or Secrecy to 0.**                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Losing should come from the enemy, not from one accidental tap.                                                                                                                                                                                                          |
| 2026-11-26 | **The bombing raid is left out for now.**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | It destroys a Facility, and Facilities don't exist yet.                                                                                                                                                                                                                  |
| 2026-11-26 | **The RNG state is stored inside `GameState`.** The reducer is `applyAction(state, action, content)` instead of taking an `rng` argument.                                                                                                                                                                                                                                                                                                                                                                                                    | CLAUDE.md shows `(state, action, rng)`, but keeping the RNG in state makes the reducer fully pure: saving the state is enough to resume, and a seed plus the action list replays a run exactly. Flagging this because it differs from the written convention.            |
| 2026-11-26 | **Engine types are the source of truth.** The content package's zod schemas are typed against them (`z.ZodType<CardDef>`), and the engine has no zod dependency.                                                                                                                                                                                                                                                                                                                                                                             | Keeps the engine dependency-free, and the compiler catches any drift between schema and engine.                                                                                                                                                                          |
| 2026-11-26 | **Content is validated when it's imported** (in the web app, sim and tests) and also by `pnpm validate` in CI.                                                                                                                                                                                                                                                                                                                                                                                                                               | Bad data fails loudly right away. It costs about 60 KB of zod in the web bundle, which is fine for now.                                                                                                                                                                  |
| 2026-11-26 | **Workspace packages export TypeScript source directly** with no build step. Vite, Vitest and tsx consume it.                                                                                                                                                                                                                                                                                                                                                                                                                                | Fewer moving parts. Revisit if build times grow.                                                                                                                                                                                                                         |
| 2026-11-26 | **TypeScript 6.0, not 7.** **Vite pinned to 8.3.8.**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | typescript-eslint doesn't support TS 7 yet. Vite 8.4.0 was released today, and pnpm's release-age guard blocks packages that new.                                                                                                                                        |
| 2026-11-26 | **Baseline balance:** Progress goal 60, Advance 2/3/4 per year, starting Budget 12. Greedy bot over 1000 runs: 63% wins, 13.5 turns, losses 60% Front / 28% Budget / 11% Secrecy.                                                                                                                                                                                                                                                                                                                                                            | The first numbers (goal 30, Advance 1/2/3, Budget 10) gave 98.6% wins in 5.6 turns, and the Front never mattered. The new values put the Front first among loss causes (pillar 1), and a run lasts about a year.                                                         |
| 2026-11-26 | **Preview deploys go to GitHub Pages** from `main` (see `.github/workflows/deploy.yml`).                                                                                                                                                                                                                                                                                                                                                                                                                                                     | It needs no extra account. On GitHub's free plan Pages only works for public repos. If the repo should be private, Cloudflare Pages or Vercel (free) are the fallback.                                                                                                   |
| 2026-11-26 | **The web app saves the current run in `localStorage`** after every action.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | The brief wants mid-run saves from day one, and since state is plain data this costs nothing.                                                                                                                                                                            |
| 2026-11-26 | **Tap Secrecy, Budget or Morale to see what it means.** A caption under them says that any of them at 0 loses the run. The enemy box now reads "Enemy's next move · hits when you end your turn."                                                                                                                                                                                                                                                                                                                                            | Kenny's first playtest: it wasn't clear what Morale and Secrecy do, or when the enemy's move takes effect.                                                                                                                                                               |
| 2026-11-26 | **The repo is public on GitHub, and the preview deploys to https://kverlin-stack.github.io/ascendancy/** on every push to `main`.                                                                                                                                                                                                                                                                                                                                                                                                            | Kenny chose public + Pages: free, with no extra accounts.                                                                                                                                                                                                                |
| 2026-11-26 | **Phase 1 direction: variety drives variance.** Prefer content and systems that make runs differ (enemy patterns, card pools, events) over deepening any single mechanic.                                                                                                                                                                                                                                                                                                                                                                    | Kenny, after the first playtest: "the key to a really good game like this is variety which leads to variance." Matches pillar 3.                                                                                                                                         |
| 2026-11-26 | **Morale sets your Effort:** 8+ gives +1 Effort per turn, 3 or less gives −1. **War weariness** costs Morale every quarter (2 after the balance pass).                                                                                                                                                                                                                                                                                                                                                                                       | Kenny's playtest: keeping Morale and Secrecy topped up was free, and that was that. Morale now matters even when it's nowhere near 0, and it keeps draining.                                                                                                             |
| 2026-11-26 | **New `fortify` primitive** blocks Front loss for the rest of the turn, covering both the enemy's move and the quarterly advance. Dig In now Fortifies instead of pushing the Front back.                                                                                                                                                                                                                                                                                                                                                    | This is the "counter it or take the hit" answer for the Front: the enemy preview now changes what you play. Pushing back (Counteroffensive) stays as the slower, pricier way to regain ground.                                                                           |
| 2026-11-26 | **Secrecy is a currency, not something to block.** Fast research spends it (Open-Air Test, Requisitioned Mainframe), and Spy Rings and Moles drain it.                                                                                                                                                                                                                                                                                                                                                                                       | Gives you a reason to let Secrecy fall, which fits the pillar of trading speed against secrecy. A block mechanic for Secrecy can come later if it's needed.                                                                                                              |
| 2026-11-26 | **Burnout rules:** each play adds 1 Burnout. At the scientist's limit their last play still resolves, then they're lost for the run and Morale drops 2. A scientist left unplayed in hand at end of turn recovers 1. `restScientists` recovers everyone. A burnout play is blocked if its Morale hit would end the run.                                                                                                                                                                                                                      | This is the simplest version that makes leaning on your star an actual choice. **Deferred:** passive abilities for scientists (the brief mentions them) and veteran status. Both come after we see whether Burnout feels good.                                           |
| 2026-11-26 | **Quarterly card picks** stand in for the map's Recruit node: after each quarter, pick 1 of 3 cards or skip. Picks are weighted by rarity (common 6, uncommon 3, rare 1). Starter and special cards are never offered.                                                                                                                                                                                                                                                                                                                       | Gets deck building and run-to-run variety into Phase 1 without building the map yet (Phase 2).                                                                                                                                                                           |
| 2026-11-26 | **New `exhaust` flag:** the card is removed for the run after one play.                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Allows powerful one-shot cards (Eureka, Grand Counterstroke) and makes the Mole removable.                                                                                                                                                                               |
| 2026-11-26 | **The enemy draws from a deck** instead of picking at random. Each action has `copies` and a `fromQuarter`, the deck only reshuffles when empty, and newly unlocked actions get shuffled in when their quarter starts. Tap the counter to see what's left.                                                                                                                                                                                                                                                                                   | Patterns you can learn and count ("two Blitzes still to come") produce more interesting decisions than pure randomness, and the escalation gives each quarter its own feel.                                                                                              |
| 2026-11-26 | **Curses:** cards can have `inHandAtEndOfTurn` effects. The Mole (added by Infiltrator) costs 1 Secrecy each time it's left in your hand, and costs 1 Effort to root out (Exhaust).                                                                                                                                                                                                                                                                                                                                                          | Lets the enemy pollute your deck. It's a reusable hook for more curses later.                                                                                                                                                                                            |
| 2026-11-26 | **Directors** live in `directors.json` with a starting deck and run rules. The first director is Minister Vera Halloran, whose rule _Wartime Footing_ gives your first Research card each turn +2 Progress, but scientists burn out 1 play sooner.                                                                                                                                                                                                                                                                                           | Phase 1 calls for one director. A rule with both an upside and a downside that touches Burnout puts pressure on the mechanic this phase has to prove.                                                                                                                    |
| 2026-11-26 | **Phase 1 balance targets:** bot win rate around 45–60%, wins last about a year (~12 turns), the Front is the #1 loss cause with every resource causing at least 10% of losses, and at least 0.5 burnouts per run. **Result:** 63.4% wins, 13.7 turns, losses Front 52% / Morale 23% / Budget 13% / Secrecy 11%, 0.39 burnouts per run.                                                                                                                                                                                                      | The win rate is slightly high and burnouts slightly low, because the bot deliberately avoids burning people out. Humans will probably burn out more, so read the sim's burnout number as a floor.                                                                        |
| 2026-11-26 | **Known bot gap:** its pick scoring undervalues Research cards (Night Shift and Wind Tunnel are almost never picked).                                                                                                                                                                                                                                                                                                                                                                                                                        | Pick rates show the bot's taste, not card quality. Worth fixing before the pick stats are used to judge cards.                                                                                                                                                           |
| 2026-11-26 | **Saves carry a `STATE_VERSION`,** and saves that don't match it are dropped. The web app shows a "Start a new run" screen instead of a blank page if rendering crashes.                                                                                                                                                                                                                                                                                                                                                                     | Game state changes shape often during prototyping, and a stale save on your phone shouldn't brick the preview.                                                                                                                                                           |
| 2026-11-26 | **`docs/WORLD.md` is the source for all names, flavor text and UI copy.** Setting: an alternate early 20th century where the Concord fights the Iron Directorate. Project Sunfire leads to the World Assembly, then the Ascendancy Program, Meridian and First Landing. Inspired by public-domain Wells, Verne and Stapledon, with no text or names taken from them.                                                                                                                                                                         | Kenny's world bible. It gives Act I and Act II one rising story (pillar 2) and a consistent voice.                                                                                                                                                                       |
| 2026-11-26 | **World names live in one file, `packages/content/src/names.ts`.** Data files use tokens like `{enemyShort}` that are filled in at load time. Validation rejects unknown tokens, and a test fails if a data file hard-codes a working name. All web UI copy lives in `apps/web/src/strings.ts`, built from the same names. The engine contains no names.                                                                                                                                                                                     | Kenny may rename anything, and a rename should be a one-line change.                                                                                                                                                                                                     |
| 2026-11-26 | **New optional `flavorText` on cards.** All 33 cards now have flavor text in the Act I voice: short and clipped, like telegrams and field reports, earnest, never cynical, and never showing casualties.                                                                                                                                                                                                                                                                                                                                     | Every run tells a story (pillar 3). Flavor text is the cheapest way to start.                                                                                                                                                                                            |
